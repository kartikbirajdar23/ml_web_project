# 🚦 Smart Traffic AI - Machine Learning Prediction System

An Enterprise-level Real-Time Traffic Prediction System using Advanced Machine Learning, Interactive Visualizations, and RESTful APIs.

## 🚀 System Architecture
- **Frontend/UI:** Streamlit with Custom Glassmorphism & Neon CSS
- **Visualization:** Interactive Leaflet.js Maps & JS Canvas Particles
- **Machine Learning:** Random Forest, Decision Tree, Gradient Boosting
- **API Engine:** FastAPI Service
- **Exporting:** Dynamic PDF Report Generator (ReportLab)

## 🛠️ How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Run Streamlit App: `streamlit run app.py`
3. Run REST API: `uvicorn api_service:app --reload`
